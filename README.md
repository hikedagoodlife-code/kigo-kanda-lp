# 氣功ビデオ講座 3月号「立ち方」LP

静的HTMLのランディングページです（ビルド不要）。

## GitHub Pages で公開する手順
1. GitHub で新しいリポジトリを作成する（例: `qigong-kanda-lp`）
2. このフォルダの中身（index.html / style.css / script.js / tokushoho.html / assets）を、リポジトリの直下にアップロードする
3. リポジトリの **Settings → Pages** を開き、Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される
